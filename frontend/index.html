Dynamic Programming methods first build an empirical model of the environment by sampling transitions from every discretized state (see rl/utils.py:estimate_mdp_model), then run Policy/Value Iteration on that model. TD(0) and TD(lambda) evaluate the policy learned by a quick internal Q-Learning run. Once training finishes, the resulting policy is automatically loaded into the live dashboard simulation.

  • Average waiting time bucket (low/medium/high)
  • High priority order waiting (yes/no)

Actions (5 high-level decisions)

  • Assign next order to an idle robotic arm
  • Assign a picked order to an idle ground robot
  • Send an idle drone to scan a zone
  • Prioritize the highest-priority queued order
  • No-op (conserve energy)
