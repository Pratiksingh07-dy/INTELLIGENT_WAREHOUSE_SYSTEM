# Intelligent Hybrid Warehouse Automation using Reinforcement Learning

A Reinforcement Learning based warehouse automation project developed for the **Reinforcement Learning** subject.

The project simulates a smart warehouse where **robotic arms, ground robots (AGVs), and aerial drones** work together. An RL-based scheduler is used to make resource allocation and task scheduling decisions with the goal of reducing waiting time, improving throughput, and using resources efficiently.

The system is implemented as a **Python-based simulation with a web dashboard** for monitoring warehouse operations and RL performance.
